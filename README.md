# MetaSchema Core

A core JSON/YAML metadata schema framework for structured content, datasets and discovery.

MetaSchema Core provides a lightweight, extensible, machine-readable foundation for defining metadata across domains. It is designed to support interoperability, validation, provenance, discoverability and structured exchange.

## Goals

- Provide a consistent metadata object model.
- Support JSON and YAML formats.
- Enable schema inheritance and extension.
- Improve discoverability and interoperability.
- Standardize provenance and citation metadata.
